### 游戏内容

- 加入移动、跳跃、双击奔跑、方块破坏与放置。
- 加入掉落物拾取和鼠标滚轮快捷栏选择。
- 加入生存与创造模式；创造模式不消耗物品并免疫伤害。
- 加入摔落伤害和脱战生命恢复。

### 文档

- 添加以英文为默认语言的 README 文档。
- 添加简体中文 README，并提供双向语言导航。
- 记录原始版本号与规范化版本号、已知功能、限制和归档状态。
- 为本次 Release 添加独立且内容完整的简体中文更新日志。
- 记录此历史标签实际采用的最终归档源码快照。
- 记录 FlatMC 已由 FlatCraft 取代。

### 已知限制

- 尚无完整死亡与重生流程，世界仍然有界。
- 石头破坏后尚不掉落方块。
- 此 Release 对应的原始源码提交和可验证原始二进制文件尚未恢复。
- GitHub 自动生成的源码压缩包实际代表 FlatMC Java Edition 最终 v0.4.0 归档源码快照，并非重建的 `v0.1.0` 源码树。
- 不保证历史存档、网络协议及构建与 FlatCraft 兼容。

### 项目状态

**已归档 / 不再维护。** 本 Release 仅为历史参考而保留。FlatMC 已由 FlatCraft 取代，本仓库不再计划进行维护或功能开发。
